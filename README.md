# RECAP Health

Post-discharge patient monitoring for Uzbekistan's health system.
Patients scan a QR code at discharge and complete a short daily
symptom check-in for 14 days. Responses are scored against
deterministic clinical thresholds, and at-risk patients are surfaced
to hospital staff for early intervention.

**Live:** https://recap-jet.vercel.app

## Stack
React 18 · Vite · Tailwind · Supabase · deployed on Vercel

## Features
- Trilingual patient interface (Uzbek / Russian / English)
- Per-patient QR enrolment at discharge
- Rule-based symptom triage — not a diagnostic model
- Hospital dashboard with ranked triage queue
- Telegram alert routing to on-call staff
